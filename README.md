# ⚛️ React 15-Day Mastery

Welcome to my **15-Day React Learning Journey** 🚀

This repository documents my journey of learning **React.js from fundamentals to real-world application development** in 15 days.

The goal of this challenge is not just to watch tutorials or learn concepts theoretically, but to **understand each concept, practice it by writing code, build projects, and maintain everything on GitHub**.

---

## 🎯 Goal

The main goal of this challenge is to become comfortable with React and gain the practical skills required to build modern, component-based web applications.

By the end of these 15 days, I aim to understand and work with:

* React fundamentals
* JSX
* Components
* Props
* Conditional rendering
* Lists and Keys
* Events
* State management
* Forms and validation
* React Hooks
* API integration
* Custom Hooks
* Context API
* `useReducer`
* React Router
* Authentication concepts
* CRUD operations
* Performance optimization
* Reusable components
* React project architecture
* React + REST API integration
